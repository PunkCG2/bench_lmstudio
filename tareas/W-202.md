# W-202: Buscador con autocompletado

Crear: `src/ui/searchBox.ts` (no modificar ningún otro archivo).

Exporta exactamente esta función:

```ts
export function initSearchBox(
  root: HTMLElement,
  search: (query: string) => Promise<Product[]>,
  options?: { debounceMs?: number }
): void;
```

`root` ya contiene este HTML:

```html
<div class="search-box">
  <input class="search-box__input" type="search">
  <ul class="search-box__results" id="search-results"></ul>
  <p class="search-box__status"></p>
</div>
```

Comportamiento:
- Escucha el evento `input` del campo. Espera `debounceMs` (por defecto 300) sin nuevas teclas antes
  de llamar a `search` con el texto sin espacios al inicio/final.
- Si el texto tiene menos de 2 caracteres: no llama a `search` (cancela también una búsqueda pendiente por
  debounce), vacía la lista y el estado.
- Por cada producto agrega `<li class="search-box__item">Nombre — $12.34</li>` (precio con 2 decimales a
  partir de `priceCents`). El nombre viene del servidor y **puede contener HTML**: debe mostrarse como
  texto literal.
- Sin resultados: lista vacía y el estado (`.search-box__status`) dice `Sin resultados`.
- Si `search` falla: lista vacía y el estado dice `Error al buscar`.
- Respuestas fuera de orden: si una búsqueda lenta termina después de una más reciente, se muestra siempre el
  resultado de la **última** búsqueda lanzada (las respuestas viejas se descartan). Lo mismo si mientras tanto el
  texto bajó de 2 caracteres: una búsqueda anterior ya no debe pintar nada.
- Accesibilidad: el input debe quedar con `aria-controls="search-results"` y el estado con
  `aria-live="polite"`.
- Cumple `docs/CONVENTIONS.md`.
