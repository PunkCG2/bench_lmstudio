# W-203: Paginación y validación en GET /api/products

Archivo: `src/api/products.ts` (no modificar ningún otro archivo).

Parámetros de query (opcionales, llegan como string). Un entero válido son solo dígitos (`"2"`); `" 2"`, `"+2"`,
`"1e1"`, `""` y números que no son enteros seguros de JavaScript son inválidos:
- `page`: entero >= 1. Por defecto 1.
- `pageSize`: entero entre 1 y el máximo vigente de la API. Por defecto, el tamaño vigente por defecto.
  Los límites vigentes están definidos en `src/config` (búscalos; no los copies como números).

Respuesta 200:
```json
{ "items": [...], "page": 1, "pageSize": 12, "total": 30, "totalPages": 3 }
```
`totalPages` es 0 si no hay productos. Pedir una página mayor a `totalPages` devuelve 200 con
`items: []`.

Respuesta 400 si algún parámetro es inválido (no numérico, decimal o fuera de rango):
```json
{ "error": { "code": "INVALID_QUERY", "field": "pageSize" } }
```

Mantén la firma de `handleGetProducts` y cumple `docs/CONVENTIONS.md`.
